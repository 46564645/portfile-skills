# Visualization Case Notes

These are learning notes from user-supplied posts, not templates or authoritative rules. Their screenshots are not stored in this skill. The Xiaohongshu notes below are based on direct review of the image carousels; the CSDN note is based on its article text and linked examples, so do not claim visual details absent from that text. Reuse the *reasoning*, not the composition or copyrighted imagery.

## 1. Many field observations on one daily cycle

Source: [信息可视化｜一张图信息太多，怎么救？](https://www.xiaohongshu.com/explore/6ac64bf40000000015000cb9?xsec_token=ABF114KS0WGPuA6SbQlA56Mb0TfFHcp74-kVpen0tBVsU%3D&xsec_source=pc_user&m_source=pinpaixiao), 13-image tutorial by 福尔丝丝.

**What the tutorial shows:** The author starts with a question about how a city's street-vendor activity changes over one day. The raw material includes vendor activity, foot traffic, patrol observations, photographs, and field notes. The author first separates those materials, then notices that each can be located by time. A 24-hour axis becomes the common coordinate. The axis is bent into a cycle because activity resumes the next day. The final composition gives different jobs to layers: a central entry point, time-linked quantitative trends, photographs at representative moments, and short field annotations around the outside. The author revises the density and keeps some quieter intervals rather than filling every part of the ring.

**Transferable advice:** When several evidence types share a meaningful coordinate, align them on it before selecting a chart style. Decide which evidence should become a measure and which needs a photograph or a sentence. Give each layer one reading job. If the recurring cycle is not central, a straight timeline may be clearer. The source's own colour choices are outside this skill's advice scope.

**Possible English recommendation:** “Use a shared 24-hour axis to align footfall, vending activity, and field observations. Put measured trends in separate tracks and attach photographs only to the moments they document.”

## 2. Many variables in one spatial comparison

Source: [信息可视化｜复杂数据怎么做成一张气泡图？](https://www.xiaohongshu.com/explore/6aa673f7000000002601b108?xsec_token=ABFVMkZtVwsjaX8iHDCXVjG6j-A55ju7a6aBdAuIwEbWM%3D&xsec_source=pc_user&m_source=pinpaixiao), 9-image tutorial by 福尔丝丝.

**What the tutorial shows:** The field dataset contains distance from a district boundary, vendor count, stall area, foot traffic, and patrol frequency. The author narrows the question to whether vendor concentration changes with distance from the boundary. Distance gets the horizontal position; vendor density/count is conveyed through repeated circles; circle size adds stall area; a line adds foot-traffic context; patrol observations and photographs become supporting information. Later slides address overlap, scale, spacing, and the order in which a reader encounters the core pattern, point-level differences, and context.

**Transferable advice:** Do not assign every variable equal visual priority. Fix the axis around the main comparison, give each remaining variable a distinct purpose, and remove or demote variables that do not help answer the question. Check whether added marks obscure one another. When bubble size encodes quantity, ensure the symbol *area* corresponds to the measure and use labels if exact reading matters.

**Possible English recommendation:** “Lead with distance from the boundary versus vendor concentration. Use size only for stall area, then place footfall and field photographs as secondary evidence so the spatial pattern remains readable.”

## 3. A timeline as an argument, not a row of dates

Source: [信息可视化 | 时间轴到底怎么排才不无聊？](https://www.xiaohongshu.com/explore/6a8eccee000000002c03c5b4?xsec_token=ABRhML0gpX_pV4jEYF1qYXzapsT9Lveb0VUBtB_pcMqrc%3D&xsec_source=pc_user&m_source=pinpaixiao), 8-image tutorial by 福尔丝丝.

**What the tutorial shows:** A list of years and events about an urban district is first reorganized into phases of change. The intended message becomes how an agricultural place became a commercial urban space. The author then matches each phase with archival photographs, buildings, news records, and brief text. In the layout, dates and nodes follow a consistent system while image size, placement, overlap, and open space vary to carry the narrative rhythm. The archival collage is justified by the historical subject matter rather than by a generic timeline template.

**Transferable advice:** Ask what changed *between* dates and label the phases. Choose visual evidence for each phase and keep dates accurate when elapsed time matters. Use varied image scale and spacing only to help the reader follow the transformation; avoid making a timeline decorative without a clear takeaway.

**Possible English recommendation:** “Group the events into phases—village, infrastructure, commercial growth, renewal—and attach one piece of visual evidence to each phase. Use dates as anchors for the transformation, not as the whole story.”

## 4. Thirty data-visualization examples as an inspiration index

Source: [CSDN: 30个惊艳的数据可视化作品，让你感受“数据之美”！](https://blog.csdn.net/aobulaien001/article/details/132610469).

**What the article describes:** It gathers examples involving event counts, sports comparisons, synchronized scrolling, weather/wind maps, before/after geographic comparisons, network links, flight paths, proportional scale, daily schedules, migration over time, rank breakdowns, and health or public-policy patterns. It supplies links to many original projects. It is an example collection, not a chart-selection tutorial or evidence that a visually striking form is automatically appropriate.

**Transferable advice:** Use an example to identify its reading task and encoding: What question is answered? Which variable becomes position, length, area, link, path, or time? What context comes from annotation or interaction? Then compare that mechanism with the student's own data before recommending it. For static English portfolio pages, do not recommend interactive or animated behaviour unless the student can present a legible static frame or sequence.

**Examples that illustrate different tasks as described in the article:**

- School shooting example: repeated marks make a count tangible; the unit per mark must be explained.
- Barcelona economic-impact example: parallel maps compare the same geography in two periods.
- Congressional voting example: links reveal similarity among actors; links need a defined meaning.
- Daily creative-routine example: one daily time coordinate aligns different activities.
- Migration example: time and geographic movement are combined; a static portfolio may need selected frames and a clear caption.

## How to use these notes in diagnosis

When a student's page resembles one of these cases, recommend the underlying operation: **find the question → find the shared coordinate or relation → assign one role to each variable/evidence type → set a reading order → remove nonessential marks → connect the visual finding to the design decision**. Cite the source as inspiration if useful. Do not present the case's format as universally optimal, and do not import its images or claims without independent evidence.
