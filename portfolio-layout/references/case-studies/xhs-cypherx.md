## 0. Format and Visual System
- About 8 landscape spreads, stacked in tall post images, plus two before/after layout comparisons.
- Type: wearable hardware + smart mirror + interaction (TouchDesigner) + service flow.
- Light grey-white ground; a few dark spreads/columns (HMW column, wireframe spread).
- **One dominant accent: rose/dusty pink** (light pink → deep magenta). An earlier version was grey-green; the author switched to pink to fit the theme.
- All photos desaturated to B/W; only data and emphasis are pink.
- **Single visual anchor:** a knee X-ray with pink injury bubbles; the product is a translucent silicone-like knee brace.

## 1. Logic Chain
Cover (research question) → BACKGROUND (personal dance story → timeline from free expression to scoring) + RESEARCH (medical institutions, scoring systems, causes, injury map, interventions → Conclusion) → QUESTIONNAIRE (150) + INTERVIEW (15, five dancer types) + 31-day training scatter → JOURNEY MAP (cyclical) → TRAINING HARM CYCLE + value-recognition analysis → HOW MIGHT WE (3 groups) → DESIGN DIRECTION → IDEATION → PRODUCT + COMPETITIVE ANALYSIS → SKETCH & ITERATION (3 rounds, modelling, MPU6050 code) → WIREFRAME DESIGN + TouchDesigner feedback → SCENE DISPLAY + SERVICE FLOW → long-term goal.
The most complete research → design derivation of the XHS set; each block's conclusion feeds the next (questionnaire causes → features; journey opportunities → tool capabilities).

## 3. Block-Writing Patterns
- Cover: rhetorical research question + three oppositions + "This project explores how A — and how B."
- Inspiration: first-person story with the cost bolded.
- Timeline: era + one-word stage.
- Chart caption: question/claim title + "This chart shows …, revealing …" with the finding in bold accent.
- **Cause → feature arrows** inside the questionnaire.
- Interview card: type + weekly hours + three slash keywords + one sentence.
- Opportunity / insight: noun-phrase title + one line.
- HMW: grouped by layer (motivation / medical / interaction), two each, with a visual metaphor row.
- Product name decomposition formula.
- Iteration: "Iteration N — keyword".
- Service: two lanes + numbered applications + one long-term goal line.

## 4. Why It Works
1. Complete derivation chain with each verdict feeding the next.
2. One strong visual anchor + one pink accent + B/W photos keep very dense content ordered.
3. Visible layout iteration toward readability.
4. Real hardware evidence: sketches, three views, modelling, sensor code, TouchDesigner output.
5. Concise copy; question headings; pink bold conclusions.

## 5. Weaknesses
1. No user testing of the prototype (comfort, usefulness, acceptance).
2. Very high density; the harm-cycle spread packs four blocks.
3. Unsourced stats, unclear samples; some numbers look illustrative.
4. No single-screen hi-fi UI; mirror–wearable interaction timing unclear.
5. Minor inconsistency ("Project 03" vs "second project").

## 6. Completeness
Full project; missing testing/validation. Present: motivation, macro background, desk research, questionnaire, interviews, behaviour data, journey, harm cycle, HMW, direction, ideation, competitors, iteration, modelling, code, wireframes, real-time visuals, scenes, service flow. Missing: prototype user testing, post-test iteration, hi-fi single screens, interaction timing, sources/samples, business numbers. Learning value: high.
