## 0. Format and Visual System
- 4 square post images, each stacking two landscape spreads → about 7 spreads (the last image repeats the outcome collage). Square crops are social-media re-layouts, not page ratios.
- Type: XR / AR-VR app (headset), UX full process.
- Near-black city photos under a heavy dark overlay; **one accent: teal** for blocks, outlines, highlighted words and floor arrows; orange as a minor second accent on the persona spread only.
- All-caps bold sans section titles top-left of each column; small white body; key words on teal highlight or in orange.
- 2–3 columns per spread; content in translucent dark cards or teal outline frames — a sci-fi HUD tone.

## 1. Logic Chain
Cover + outcome collage → BACKGROUND (social structures → personal pressure collage) + RESEARCH (working hours, happiness charts → Summary) → PERSONA + DESIGN THINKING PATHWAY (think/say/hear/do map → Conclusion) + USER JOURNEY MAP → CONCEPT storyboard + TECHNICAL RESEARCH + EXPERIMENTAL PROCESS → USERFLOW + WIREFRAMES + HIGH FIDELITY → scene collage.
Every double-diamond stage has a block, but each is shallow, and there is a jump: research is about overwork, the journey's opportunities are "relaxation", yet the concept is "experience other people's cities" — the "why cross-city" insight is missing.

## 3. Block-Writing Patterns
- Cover: tension sentence + "To address this challenge, I designed X, which aims to use [tech] to enable users to [action], thereby [value]."
- Background: central figure + radiating roles (name + one function line) → four consequences (noun + one causal line).
- Research: charts + boxed "Summary:" with highlighted keywords.
- **Empathy coordinate map**: Think/Say/Hear/Do axes with scattered phrase pills → numbered Conclusion.
- Storyboard: one "The user + verb …" line per frame; grey → line art → colour.
- Tech/experiment: highlighted label + colon + one sentence.
- Hi-fi: page name + "X page displays / can …".

## 4. Why It Works
1. One teal accent on dark ground keeps seven spreads unified and on-theme for XR.
2. Every process stage has a block, so readers can map the method instantly.
3. **Userflow → wireframes → hi-fi triptych** in one spread shows structure becoming interface left to right.
4. Storyboard uses colour as narrative.
5. Real photos composited with UI make scenes plausible.

## 5. Weaknesses
1. Problem → solution leap; no "why another city" insight.
2. Decorative, contradictory or unsourced data; persona numbers don't add up.
3. No usability testing of the design; the "experiment" is a device trial.
4. Many English errors; tiny text; outcome images uncaptioned and repeated.

## 6. Completeness
Full project but shallow. Present: background, research, persona, empathy map, journey, storyboard, tech research, device trial, userflow, wireframes, hi-fi, scenes. Missing: primary research evidence and sources, the key insight, competitor analysis, usability testing and iteration, core interaction detail (entering/participating in another city), reflection. Learning value: medium-high for layout; avoid its decorative charts.
