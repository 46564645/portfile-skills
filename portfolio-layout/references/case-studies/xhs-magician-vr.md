## 0. Format and Visual System
- 6 ultra-wide spreads (post slices about 2.67:1) plus one low-res overview strip.
- Type: VR game / emotional therapy, built in Unreal Engine 5.
- Pure black ground with thin white perspective-grid "tunnels" (a theatre corridor / subconscious metaphor).

## 1. Logic Chain
Cover (what + for whom + tools) → BACKGROUND (prevalence data for two groups: adolescents and menopausal women) → why it happens (4 causes) → RESEARCH (two interviewees + theory) → ANALYSIS (consequences if unsolved + persona, pains, needs) → CONCEPT (VR-therapy mechanisms → concept → 3-layer game flow → UE5 making) → MAIN SCENES (each scene's look + therapeutic role) → FINAL OUTPUT + Reflection.
Bridge: pain "resistance to traditional therapy / no safe channel for expression" → need "a private, safe, immersive environment" → technical research shows VR can provide it → concept.

## 3. Block-Writing Patterns
- Claim headline: put the page's verdict in the H2.
- Data block: big number + population + source + one bolded comparison.
- Interview block: name + age + state-word box + first-person quote + **Attempted Solutions** (why current options fail).
- Theory block: "A vs B in group 1 / C vs D in group 2" contrast words + one mechanism sentence.
- Consequence chain: three escalating nodes (individual → cognitive → family).
- Technical research: definition + 3 mechanisms that each answer a stated need.
- Scene block: appearance + therapeutic role.
- Reflection: named shortcomings + next step.

## 4. Why It Works
1. Two user groups run in parallel everywhere (data, interviews, theory, persona) — symmetric and credible.
2. "Attempted Solutions" creates the evidence bridge to VR.
3. The three-layer Game Flow maps therapy stages to levels — the key diagram for any game project.
4. A very tight visual system; the grid tunnel itself is the theatre/subconscious metaphor.
5. Honest reflection.

## 5. Weaknesses
- No playtest or therapeutic validation (admitted in the reflection).
- Copy errors: a second scene block keeps the "Scene 1 Bedroom" title over Scene 3 text; duplicated theory labels; one cause label doesn't match its text; a placeholder video link.
- Background page is dense with small type; several stats lack precise sources.
- No sketches or early concepts; research jumps straight to a finished flow.

## 6. Completeness
Full project, missing testing. Present: background, causes, interviews, theory, persona/pains/needs, technical research, concept, game flow, making, final, reflection. Missing: user/efficacy testing, iteration comparison, early ideation.
