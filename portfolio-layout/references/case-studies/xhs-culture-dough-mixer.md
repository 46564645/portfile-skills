## 0. Format and Visual System
- About 10 landscape sections across 3 tall post images.
- Type: interactive installation + hardware programming (soft pneumatic tentacles knead dough; Arduino, Maya, 3D print).
- Light grey-white ground; cover and delivery shots on white drapery so photos merge with the page.
- One accent: saturated Klein/electric blue — headings, blocks, outline frames, map highlights, bar charts, even the QR code.

- Components: white cards with offset blue shadow; round avatars; blue tool tags ("Maya@", "Arduino@", "3D print@"); thin blue leader arrows. Collage people are desaturated on blue blobs; object photos keep colour.

## 3. Block-Writing Patterns
- Cover subtitle = work type + issue + purpose.
- Concept evolution = dated definition cards; the highlighted last card is the definition the project uses.
- Data page ends with two numbered conclusions (scale + trend = worth doing).
- Problem map = caps problem name + short symptoms, arranged around one person.
- Interview = avatar + quantified identity ("abroad for N years") + one bolded sentence.
- Ideation = "Current issues → Design concept" rows + one HMW.
- **Metaphor-justification page** = literal definition + 4 numbered cultural reasons + one conclusion bar.
- **Structure analysis** = part name + "By detecting X, Y is controlled" + code.
- Process = step sentence + photo group + tool tag.

## 4. Why It Works
1. One blue across every element gives a strong, clean identity.
2. A full argument chain: scale/trend → six problems → four voices → issue/solution rows → HMW → a page answering "why dough".
3. Hardware credibility: structure analysis with code, and many process photos from modelling to wiring.
4. Interviews carry quantified identities and on-site photos.
5. Small components (offset shadow, tool tags) are consistent.

## 5. Weaknesses
- No audience testing or reflection; "raising social responsibility" is never checked.
- The delivery page doesn't explain the emotional mapping (what the dough or the tentacles stand for).
- Typos and data conflicts: a doubled section title, a truncated label, TFC/TLC acronyms mixed, two different figures for the same country, a duplicated part title.
- Process after the final without a transition sentence.

## 6. Completeness
