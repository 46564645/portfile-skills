## 4. What Is Missing Across Cases
None of the seven XHS cases shows user testing of the student's own design followed by iteration. "Testing" in them means device trial or component debugging. When diagnosing, check this stage first (see SKILL.md and `../narrative-logic-chains.md` §8).
