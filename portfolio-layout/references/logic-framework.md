# Logic Framework

Use for project story, page order, portfolio structure, research-to-output flow, and transforming coursework into portfolio projects.

## Source Coverage

From Tip items 02, 03, 07, 08, 13, 15, 20, 22, 24, 25, and 26.

## Core Principle

Layout is not only visual styling. The page must make the design thinking readable. First build the story and information hierarchy, then refine the visual surface.

## WHY -> HOW -> WHAT

Use this when a project feels like a material pile:

- **WHY**: Why this project exists. Show background, motivation, pain point, user/context, or research question.
- **HOW**: How the designer investigated and developed the solution. Show research, analysis, concept development, decisions, prototypes, tests, and iteration.
- **WHAT**: What was finally made. Show final product/service/system, interaction, scenario, and results.

This structure is especially useful for pages that currently mix background, process, and outcome without order.

## Inspiration -> Research -> Development -> Final

Use this as a four-stage portfolio skeleton:

- **Inspiration**: project motivation, story, initial observation, design direction.
- **Research**: data, users, fieldwork, interviews, competitor analysis, visualized insights.
- **Development**: concept exploration, sketches, models, prototypes, decision logic, iterations.
- **Final**: final work, functions, scenario images, key interaction, links, or outcome evidence.

Each stage should answer a different question. Do not let Research consume the whole project.

## Four-Step Page-Building Workflow

From item 02:

1. **梳理表达逻辑**: Lay out raw text first, identify logical relationships, and decide the page's key message.
2. **制作视觉素材**: Create visuals that match the meaning, not random decoration. For abstract concepts, find concrete examples and combine representative objects.
3. **初版诊断**: Check whether text is too heavy, image/text are disconnected, or blocks lack hierarchy.
4. **再次优化**: Use scale, lines, captions, image placement, and path-based text to emphasize cause-effect or contrast.

For a page with two related ideas, identify which is cause, which is result, and which deserves emphasis.

## Coursework to Portfolio: Six-Step Upgrade

Use when the user says they only have assignments or course projects:

1. **选题**: Extract a research question from an assignment. Ask whether it connects to real life, social context, user needs, material experiments, systems, or cross-disciplinary potential.
2. **明确命题**: Define the project anchor: whose problem, what problem, and what behavior/awareness/emotion the design wants to guide.
3. **调研分析**: Do not only collect. Analyze and judge. Combine first-hand/second-hand, visual/real-world, and competitor research.
4. **设计过程**: Show choices, not only steps. Include divergence, convergence, prototype validation, user testing, and optimization.
5. **产出**: Translate concept into visual language, detailed models, information graphics, motion, interface, environment simulation, and consistent visual system.
6. **整体逻辑**: Build a designer profile across projects through theme, naming, chapter feeling, and project order.

## Storyline Method

From the city-village sunlight case:

1. Start with a personal discovery or observed event.
2. Raise the social/design problem.
3. Explain background context.
4. Deepen the argument with evidence.
5. Compare groups, conditions, prices, pain points, or consequences.
6. Summarize the conclusion that leads toward design action.

Then assign story beats to page blocks before designing the final visual treatment.

## Interaction/UX Logic

Use a process path: topic -> research -> need analysis -> concept design -> evaluation and adjustment -> final presentation.

Do not let interface screenshots replace decision logic. Show why a concept was selected, how user needs shaped the flow, and how validation changed the result.

## Target Audience and Portfolio Positioning

From item 20:

- Before layout, clarify who will read it: overseas admissions,保研导师,考研复试导师, or professional reviewers.
- For保研/考研, emphasize academic potential, research process, and logical rigor.
- For overseas study, emphasize personal voice, critical thinking, experimentation, and cross-disciplinary exploration.
- Review target programs, tutors, and school style, then adjust project order and emphasis.

## Storytelling and Designer Identity

From item 22 and 25:

- A portfolio should answer: what kind of designer am I, what experiences do I have, what abilities do I show, and what fields do I care about?
- Show only the best work and strengthen the core through storytelling.
- It can be useful to include failed or abandoned ideas when they show challenge handling and decision making.
- Build a continuous project mainline, such as social公益, vulnerable groups, technology and humanity, or sensory interaction.

## Evaluation Logic

From item 24, top-school evaluation often looks for:

- **立意研究**: original question, real need, and complete logic loop.
- **设计分析能力**: tools that bridge information to design opportunity, such as Persona, user journey, fishbone, empathy map, affinity map.
- **团队合作能力**: role, conflict resolution, and learning when team projects are included.
- **故事叙述能力**: design narrative that connects discovery to implementation without method dumping.

## System and Narrative Thinking

From item 26:

- **系统化思维**: Show micro interaction and macro service/ecosystem together. Explain information architecture, task flow, online/offline relations, and hardware/software linkage.
- **叙事化体验**: Begin from the feeling the design creates. Use story, space, physical touchpoints, and interpersonal interaction to build immersive experience.
- Strong interaction projects often combine precise systems with emotional storytelling.
